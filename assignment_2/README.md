# IITK QR Code Attendance Bot

An automated, modular Telegram bot built with Node.js to streamline event and classroom attendance. Volunteers simply snap and send a photo of an IITK ID card; the bot immediately processes the image, extracts the encrypted identity data, and manages real-time registration constraints.

---

## Key Features

- **Image Processing:** Utilizes `jimp` to decode image data into raw pixel buffers.
- **QR Extraction:** Employs `jsqr` to parse binary matrices into meaningful string schemas.
- **Smart Data Extraction:** Leverages Regex token parsing to cleanly find 6-digit student credentials.
- **Range Validation:** Restricts check-ins to authorized cohorts (strictly within the `240001–240400` range).
- **Local Persistence Engine:** Prevents double-marking by recording unique timestamps into a structured JSON file system.
- **Live Dashboards:** Intercepts administrative text triggers like `/report` to supply real-time sorting analytics.

---

## Project Architecture

The codebase strictly follows a decoupled, single-responsibility principle architecture:

| File Name       | Functional Domain   | Technical Overview                                               |
| :-------------- | :------------------ | :--------------------------------------------------------------- |
| `qr.js`         | Image Manipulation  | Extracts raw bitmap matrices and handles image decoding loops.   |
| `parser.js`     | Identity Extraction | Runs Regex pattern matching and range authorization rules.       |
| `attendance.js` | Local File Storage  | Handles transactional I/O states on `attendance.json`.           |
| `bot.js`        | Interface & Routing | Orchestrates Telegram event long-polling loops and user replies. |

## Configuration & Environment Setup

### 1. External Dependencies

Ensure your development environment contains all critical external runtimes. Install them by running:

```bash
npm install
```

### 2. Environment Variables Configuration

To run safely without leaking security credentials to public version control systems, this project abstracts access vectors into an environment layer.

- Locate the .env.example file in the root directory.
- Duplicate it and rename the copy to .env:

```bash
cp .env.example .env
```

- Open .env and replace the placeholder text with your live HTTP API Token generated by Telegram's BotFather:

Code snippet

```
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
```

Security Advisory: The .env file contains sensitive entry parameters and is automatically ignored by Git rules inside .gitignore. Never upload it to public servers.

## Execution Instructions

Start the application interface loop by firing up the main runtime manager:

```bash
node bot.js
```

Supported Interface Actions

- /start — Registers the user channel and displays greeting deployment info.
- /report — Displays complete administrative statistics including overall metrics and sorted lists of check-ins.
- Photo Upload — Send a compressed or raw image containing an IITK ID card QR code. The bot will automatically analyze the image, run identity parsing metrics, write data to disk if eligible, or provide clean error handling logs (e.g., if the user is out-of-range or already marked present).
